# Figure 7：iPSC 对应关系

```bash
python figures/figure7/run.py
```

只计算 F7f、F7g 和 F7h。默认输出为 `results/figures/figure7/`，可用 `--output` 指定；每个面板输出 PDF、SVG 和 PNG。

- **F7f**：从完整 235 个可评价实体按固定保留标记得到 191 个实体，其中 158 个正相关，并重算直方图。
- **F7g**：八个至少含五个药物的 MoA，共 104 个成员；每类大点和成员小点使用该类共同可评价的细胞株。图中 P 为未经多重校正的精确双侧置换概率。

- **F7h**：固定的 CPI-360、EI1、romidepsin 和 dacinostat 四例，比较十株 iPSC 的预测 RMS 排名与遗传响应排名，共 40 个点。

`source_data/` 仅包含 235 实体审计、MoA 汇总与成员点，以及四例统计与排名点五张科学输入表。模型预测、遗传评分与 235 实体的完整重算入口保留在 `experiments/ipsc/`。默认同时核验 235/191/158、八类 MoA 和 104 个成员；完整模型资源存在时还复算源定向遗传评分。

关联分析使用固定细胞株及基于结果的保留集合，遗传测量与模型输入有重用，属于探索性对应，不能将正相关比例解释为独立药物实验准确率。
