# Third-party code and resources

The G2CP author-backbone code is in `experiments/comparisons/g2cp/author/`; its supplied MIT notice is preserved at `experiments/comparisons/g2cp/LICENSE`. The HyperMap author network is in `experiments/comparisons/hypermap/author_model.py`, with the supplied MIT notice at `experiments/comparisons/hypermap/LICENSE`. Their local adaptations and fixed experiment settings are documented alongside them.

The project uses frozen UniPert representations. The UniPert encoder and its complete repository are not redistributed here. See the [UniPert source project](https://github.com/TencentAILabHealthcare/UniPert) for its original code and terms. LINCS response resources originate from the [CLUE/LINCS data collection](https://clue.io/data/CMap2020#LINCS2020). iPSC data source URLs and checksums are listed in `experiments/ipsc/raw_data_manifest.json`.

Chemical annotations and the Hallmark GMT retain their respective source terms. The model bundle manifest records the underlying source collections. A code licence does not automatically grant rights to redistribute third-party data or embeddings.

No separate licence grant is made for GRAFT code, model weights or prepared resources in this release. The supplied third-party code retains its original licence notices, and third-party data and representations retain their source terms.
